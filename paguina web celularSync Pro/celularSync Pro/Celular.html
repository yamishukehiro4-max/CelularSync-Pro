Gestión Inteligente de Inventario y Ventas

Descubre el sistema definitivo desarrollado en Python. Control de stock, facturación en PDF, estadísticas en tiempo real y carritos de compra, todo en un entorno seguro y altamente optimizado.

¿De qué trata CelularSync Pro?

CelularSync Pro (anteriormente conocido como Nexus GX) es un sistema integral de software diseñado específicamente para la administración completa de tiendas de dispositivos móviles. Se trata de una plataforma que unifica el control del inventario, la facturación directa a clientes y la generación de métricas de ventas en una sola interfaz fluida y fácil de usar, desarrollada desde cero en Python y conectada a bases de datos relacionales.

¿Para qué sirve?

El sistema sirve para eliminar por completo el uso de papel, cuadernos o bases de Excel desordenadas. Permite registrar cada entrada y salida de mercancía (celulares, fundas, audífonos, repuestos). Sirve para que los dueños de negocios sepan exactamente cuánto dinero tienen invertido, qué productos están a punto de agotarse y cuáles son los dispositivos más vendidos gracias a sus gráficos integrados.

Impacto en el día a día

En el día a día, CelularSync Pro le ahorra horas de trabajo a los administradores. Evita los errores humanos al hacer el "cuadre de caja" diario, previene el robo hormiga al tener un registro exacto del stock, y acelera el proceso de venta. Un cliente llega, el vendedor selecciona el producto, lo agrega al carrito virtual del sistema y con un clic le imprime su comprobante en PDF. Todo en menos de 1 minuto.

El Origen y los Intentos

Este proyecto nació como un reto monumental en PyCharm para el módulo de Desarrollo de Software. Pasamos por incontables intentos y errores; desde botones en Tkinter que no respondían, hasta consultas SQL que no actualizaban el stock al confirmar una venta. Cada error fue una oportunidad de aprendizaje. Depuramos el código, mejoramos la interfaz gráfica integrando Matplotlib para las estadísticas y creamos una arquitectura robusta que hoy funciona de manera impecable.

Profundizando en el Código

La arquitectura de CelularSync Pro se basa en el patrón Modelo-Vista-Controlador (MVC). Esto significa que separamos estrictamente la parte visual (lo que ve el usuario) de la lógica de negocio (los cálculos) y de la base de datos. Esta modularidad nos permitió trabajar en PyCharm de forma mucho más limpia.

Por ejemplo, cuando se realiza una venta, el Controlador recibe la orden, valida que haya stock suficiente, le dice a la Base de Datos (Modelo) que reste esa cantidad, y finalmente actualiza la tabla en la Vista (Tkinter). Además, implementamos validaciones de seguridad para evitar inyecciones SQL.

El Poder del Administrador

El núcleo de gestión de CelularSync Pro cuenta con herramientas exclusivas.

Agregar Productos

Interfaz para registrar nuevos dispositivos. Permite ingresar el IMEI, marca, modelo, precio de costo y precio de venta. El sistema calcula el margen de ganancia automáticamente. Sirve para mantener el catálogo actualizado y clasificar entre celulares, accesorios o repuestos.

Gestión de Usuarios

Buscador integrado para gestionar las cuentas del personal. El administrador puede crear perfiles para cajeros con permisos limitados o perfiles administrativos. Permite buscar usuarios por ID o nombre al instante.

Métricas de Venta

Panel de control gerencial. Genera reportes sobre los días de mayor flujo de clientes, las marcas más rentables y alertas de productos estancados. Toda esta información se presenta en cuadros y gráficas coloridas para una fácil interpretación del dueño.

Búsqueda y Filtrado Avanzado

Permite rastrear cualquier venta buscando por el nombre del cliente, modelo del producto o fecha exacta. Además, incluye un panel especial para buscar facturas específicas de clientes registrados y re-imprimir sus comprobantes HTML/PDF con un solo clic en caso de pérdida.
